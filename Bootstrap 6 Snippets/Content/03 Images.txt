WHAT IT DOES
Documentation and examples for opting images into responsive behavior (so they
never become wider than their parent) and add lightweight styles to them—all
via classes.

HOW TO USE IT
These classes style normal HTML elements. Add them to the matching tag
(headings, paragraphs, tables, images). Most content styles need no
JavaScript.

READING GUIDE
`code` marks a class name, attribute, or value you type into your HTML. Code
blocks are complete and ready to paste into a page that loads Bootstrap 6.
Indentation inside code is meaningful. New to Bootstrap? Read "00 Beginner's

========================================================================
RESPONSIVE IMAGES
========================================================================

Images in Bootstrap are made responsive with `.img-fluid`. This applies
`max-width: 100%;` and `height: auto;` to the image so that it scales with the
parent width.

Example code (HTML):

<img src="..." class="img-fluid" alt="...">

========================================================================
IMAGE THUMBNAILS
========================================================================

In addition to our border-radius utilities, you can use `.img-thumbnail` to
give an image a rounded 1px border appearance.

Example code (HTML):

<img src="..." class="img-thumbnail" alt="...">

========================================================================
ALIGNING IMAGES
========================================================================

Align images with the helper float classes or text alignment classes.
`block`-level images can be centered using the `.mx-auto` margin utility
class.

Example code (HTML):

<img src="..." class="rounded float-start" alt="...">
<img src="..." class="rounded float-end" alt="...">

Example code (HTML):

<img src="..." class="rounded mx-auto d-block" alt="...">

Example code (HTML):

<div class="text-center">
  <img src="..." class="rounded" alt="...">
</div>

========================================================================
FIGURES
========================================================================

Anytime you need to display a piece of content—like an image with an optional
caption, consider using a `<figure>` element. Figures are flex containers in
Bootstrap, so you can easily modify the layout and alignment with our flex
utilities.

Use the included `.figure` and `.figure-caption` classes to provide some
baseline styles for the HTML5 `<figure>` and `<figcaption>` elements. Images
in figures have no explicit size, so be sure to add the `.img-fluid` class to
your `<img>` to make it responsive.

Example code (HTML):

<figure class="figure">
  <img src="..." class="img-fluid rounded-3" alt="...">
  <figcaption class="figure-caption">A caption for the above image.</figcaption>
</figure>

And with a reverse alignment:

Example code (HTML):

<figure class="figure align-items-end">
  <img src="..." class="img-fluid rounded-3" alt="...">
  <figcaption class="figure-caption">A caption for the above image.</figcaption>
</figure>

========================================================================
PICTURE
========================================================================

If you are using the `<picture>` element to specify multiple `<source>`
elements for a specific `<img>`, make sure to add the `.img-*` classes to the
`<img>` and not to the `<picture>` tag.

Example code (HTML):

<picture>
  <source srcset="..." type="image/svg+xml">
  <img src="..." class="img-fluid img-thumbnail" alt="...">
</picture>

VARIABLES
------------------------------------------------------------------------

Images use local CSS variables on `.img-thumbnail` for real-time
customization. Values for the CSS variables are generated from Sass maps
unique to each component and applied to the aforementioned class.

Example code (SCSS):

// stylelint-disable-next-line scss/dollar-variable-default
$thumbnail-tokens: defaults(
  (
    --thumbnail-padding: .25rem,
    --thumbnail-bg: var(--bg-body),
    --thumbnail-border-width: var(--border-width),
    --thumbnail-border-color: var(--border-color),
    --thumbnail-border-radius: var(--radius-5),
    --thumbnail-box-shadow: var(--box-shadow-sm),
  ),
  $thumbnail-tokens
);

And for figures as well:

Example code (SCSS):

// stylelint-disable-next-line scss/dollar-variable-default
$figure-tokens: defaults(
  (
    --figure-gap: calc(var(--spacer) * .5),
    --figure-caption-font-size: var(--font-size-sm),
    --figure-caption-color: var(--fg-3),
  ),
  $figure-tokens
);
