JAVASCRIPT SETUP  (read this first)
------------------------------------------------------------------------
Include the bundle once per page, before </body>:

  <script src="https://cdn.jsdelivr.net/npm/bootstrap@6.0.0-alpha.1/dist/js/bootstrap.bundle.min.js"></script>

The data API initialises strength meters from `data-bs-strength`. It looks for a password input in the same parent container.

Automatic (data API):

<div>
  <input type="password" class="form-control" id="myPassword">
  <div class="strength" data-bs-strength>
    <div class="strength-segment"></div>
    <div class="strength-segment"></div>
    <div class="strength-segment"></div>
    <div class="strength-segment"></div>
  </div>
</div>

Manual initialisation:

const strength = new bootstrap.Strength(element, {
  input: '#myPassword',
  minLength: 10
})

Reuse an existing instance:

const strength = bootstrap.Strength.getOrCreateInstance(element)

USAGE > VIA JAVASCRIPT
Example 7  |  JS
------------------------------------------------------------------------
const element = document.querySelector('.strength')
const strength = new bootstrap.Strength(element, {
  input: '#my-password-input',
  minLength: 10,
  messages: {
    weak: 'Too weak',
    fair: 'Could be better',
    good: 'Good password',
    strong: 'Excellent!'
  }
})

------------------------------------------------------------------------
USAGE > OPTIONS > DEFAULT WEIGHTS
Example 8  |  JS
------------------------------------------------------------------------
{
  minLength: 1,        // Meets minimum length
  extraLength: 1,      // 4+ characters over minimum
  lowercase: 1,        // Contains lowercase letters
  uppercase: 1,        // Contains uppercase letters
  numbers: 1,          // Contains numbers
  special: 1,          // Contains special characters
  multipleSpecial: 1,  // Multiple special characters
  longPassword: 1      // 16+ characters
}

------------------------------------------------------------------------
USAGE > OPTIONS > CUSTOM WEIGHTS
Example 9  |  JS
------------------------------------------------------------------------
// Disable uppercase requirement, make special chars worth more
new bootstrap.Strength(element, {
  weights: {
    uppercase: 0,   // Don't require uppercase
    special: 2      // Special chars worth 2 points
  },
  thresholds: [3, 5, 7]  // Adjust thresholds for new max score
})

------------------------------------------------------------------------
USAGE > OPTIONS > CUSTOM SCORER
Example 10  |  JS
------------------------------------------------------------------------
// Fully custom scoring logic
new bootstrap.Strength(element, {
  scorer: (password) => {
    let score = 0
    if (password.length >= 12) score += 4
    if (/[!@#$%]/.test(password)) score += 4
    return score
  },
  thresholds: [2, 4, 6]
})

------------------------------------------------------------------------
USAGE > METHODS
Example 11  |  JS
------------------------------------------------------------------------
const element = document.querySelector('.strength')
const strength = bootstrap.Strength.getOrCreateInstance(element)

// Get current strength
console.log(strength.getStrength()) // 'fair'

------------------------------------------------------------------------
USAGE > EVENTS
Example 12  |  JS
------------------------------------------------------------------------
const element = document.querySelector('.strength')

element.addEventListener('strengthChange.bs.strength', event => {
  console.log('Strength:', event.strength) // 'weak', 'fair', 'good', 'strong'
  console.log('Score:', event.score) // 0-8
})

CSS > VARIABLES
Example 14  |  SCSS
------------------------------------------------------------------------
Note: Password strength use local CSS variables on `.strength` for real-time customization. Values for the CSS variables are generated from Sass maps unique to each component and applied to the aforementioned class.

// stylelint-disable-next-line scss/dollar-variable-default
$strength-tokens: defaults(
  (
    --strength-height: .375rem,
    --strength-gap: .25rem,
    --strength-margin-top: .25rem,
    --strength-border-radius: var(--radius-pill),
    --strength-bg: var(--bg-2),
    --strength-color: var(--bg-2),
    --strength-weak-color: var(--danger-bg),
    --strength-fair-color: var(--warning-bg),
    --strength-good-color: var(--info-bg),
    --strength-strong-color: var(--success-bg),
  ),
  $strength-tokens
);

------------------------------------------------------------------------
CSS > SASS LIST
Example 15  |  SCSS
------------------------------------------------------------------------
Note: We use a Sass list to define the strength levels, allowing you to easily add or modify levels by overriding the default list. The order of the levels matters, as it will be used to determine the width of the strength meter.

$strength-levels: weak, fair, good, strong;
