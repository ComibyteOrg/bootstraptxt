WHAT IT DOES
Use these helpers to visually hide elements but keep them accessible to
assistive technologies.

HOW TO USE IT
Add the helper class to the element you want to affect. Helpers are small,
single-purpose classes that do one job.

READING GUIDE
`code` marks a class name, attribute, or value you type into your HTML. Code
blocks are complete and ready to paste into a page that loads Bootstrap 6.
Indentation inside code is meaningful. New to Bootstrap? Read "00 Beginner's
Guide.txt" first.

ON THIS PAGE
  Title for screen readers

Visually hide an element while still allowing it to be exposed to assistive
technologies (such as screen readers) with `.visually-hidden`. Use
`.visually-hidden-focusable` to visually hide an element by default, but to
display it when it’s focused (e.g. by a keyboard-only user).
`.visually-hidden-focusable` can also be applied to a container–thanks to
`:focus-within`, the container will be displayed when any child element of the
container receives focus.

Example code (HTML):

<h2 class="visually-hidden">Title for screen readers</h2>
<a class="visually-hidden-focusable" href="#content">Skip to main content</a>
<div class="visually-hidden-focusable">A container with a <a href="#">focusable element</a>.</div>

Both `visually-hidden` and `visually-hidden-focusable` can also be used as
mixins.

Example code (SCSS):

// Usage as a mixin

.visually-hidden-title {
  @include visually-hidden;
}

.skip-navigation {
  @include visually-hidden-focusable;
}
