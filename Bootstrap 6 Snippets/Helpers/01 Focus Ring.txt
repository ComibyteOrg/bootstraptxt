WHAT IT DOES
Utility classes that allows you to add and modify custom focus ring styles to
elements and components.

HOW TO USE IT
Add the helper class to the element you want to affect. Helpers are small,
single-purpose classes that do one job.

READING GUIDE
`code` marks a class name, attribute, or value you type into your HTML. Code
blocks are complete and ready to paste into a page that loads Bootstrap 6.
Indentation inside code is meaningful. New to Bootstrap? Read "00 Beginner's
Guide.txt" first.

ON THIS PAGE
  Example
  Variants
  Custom colors

The `.focus-ring` helper modifies the default `outline` for focus states with
one that can be more easily customized. Focus ring is made up of a series of
CSS variables, inherited from the `:root` level, that can be modified for any
element or component.

VARIANTS
========================================================================

Change the color of the focus ring with the theme color utility classes. The
helper class pulls in the `--bs-theme-focus-ring` CSS variable for the given
theme color.

========================================================================
CUSTOM COLORS
========================================================================

Modify the `--bs-focus-ring-color` CSS variable as needed to change the
default appearance. Use existing theme variables or your own colors. When
using your own colors, we recommend using `light-dark()` for color mode
support and `color-mix()` to ensure colors deviate slightly for more contrast
on different backgrounds.

Example code (HTML):

<a href="#" class="d-inline-flex focus-ring py-1 px-2 text-decoration-none border rounded-2" style="--bs-focus-ring-color: var(--bs-success-focus-ring)">
  Green focus ring
</a>
