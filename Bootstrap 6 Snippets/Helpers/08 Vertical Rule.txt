WHAT IT DOES
Use the custom vertical rule helper to create vertical dividers like the
`<hr>` element.

HOW TO USE IT
Add the helper class to the element you want to affect. Helpers are small,
single-purpose classes that do one job.

========================================================================
HOW IT WORKS
========================================================================

Vertical rules are inspired by the `<hr>` element, allowing you to create
vertical dividers in common layouts. They’re styled just like `<hr>` elements:

- They’re `1px` wide
- They have `min-height` of `1em`
- Their color is set via `currentColor` and `opacity`

Customize them with additional styles as needed.

========================================================================
EXAMPLE
========================================================================

Example code (HTML):

<div class="vr"></div>

Vertical rules scale their height in flex layouts:

Example code (HTML):

<div class="d-flex" style="height: 200px;">
  <div class="vr"></div>
</div>

========================================================================
WITH STACKS
========================================================================

They can also be used in stacks:

Example code (HTML):

<div class="hstack gap-3">
  <div class="p-2">First item</div>
  <div class="p-2 ms-auto">Second item</div>
  <div class="vr"></div>
  <div class="p-2">Third item</div>
</div>

========================================================================
CSS
========================================================================

Vertical rules use a CSS variable with fallback for their default border
width. Out of the box, `--vr-border-width` is unassigned, meaning it defaults
to the value of `--border-width`.
