========================================================================
SCROLLSPY
Bootstrap 6.0  |  Local component reference
Source: https://getbootstrap.com/docs/6.0/components/scrollspy
Requires JavaScript plugin: yes  (see JAVASCRIPT SETUP below)
========================================================================

Automatically update Bootstrap navigation or list group components based on scroll position to indicate which link is currently active in the viewport.

------------------------------------------------------------------------
JAVASCRIPT SETUP  (read this first)
------------------------------------------------------------------------
Include the bundle once per page, before </body>:

  <script src="https://cdn.jsdelivr.net/npm/bootstrap@6.0.0-alpha.1/dist/js/bootstrap.bundle.min.js"></script>

The data API initialises scrollspy from `data-bs-spy="scroll"`.

Automatic (data API):

<body data-bs-spy="scroll" data-bs-target="#myNav" tabindex="0">

Manual initialisation:

const scrollSpy = new bootstrap.ScrollSpy(document.body, {
  target: '#myNav'
})

Reuse an existing instance:

const scrollSpy = bootstrap.ScrollSpy.getOrCreateInstance(document.body)

NON-VISIBLE ELEMENTS
Example 5  |  JS
------------------------------------------------------------------------
Note: Target elements that aren’t visible will be ignored and their corresponding nav items won’t receive an `.active` class. Scrollspy instances initialized in a non-visible wrapper will ignore all target elements. Use the `refresh` method to check for observable elements once the wrapper becomes visible.

document.querySelectorAll('#nav-tab>[data-bs-toggle="tab"]').forEach(el => {
  el.addEventListener('shown.bs.tab', () => {
    const target = el.getAttribute('data-bs-target')
    const scrollElem = document.querySelector(`${target} [data-bs-spy="scroll"]`)
    bootstrap.ScrollSpy.getOrCreateInstance(scrollElem).refresh()
  })
})

USAGE > VIA DATA ATTRIBUTES
Example 6  |  HTML
------------------------------------------------------------------------
Note: To easily add scrollspy behavior to your topbar navigation, add `data-bs-spy="scroll"` to the element you want to spy on (most typically this would be the `<body>`). Then add the `data-bs-target` attribute with the `id` or class name of the parent element of any Bootstrap `.nav` component.

<body data-bs-spy="scroll" data-bs-target="#navbar-example">
  ...
  <div id="navbar-example">
    <ul class="nav nav-tabs" role="tablist">
      ...
    </ul>
  </div>
  ...
</body>

USAGE > METHODS
Example 8  |  JS
------------------------------------------------------------------------
Note: Here’s an example using the refresh method:

const dataSpyList = document.querySelectorAll('[data-bs-spy="scroll"]')
dataSpyList.forEach(dataSpyEl => {
  bootstrap.ScrollSpy.getInstance(dataSpyEl).refresh()
})
