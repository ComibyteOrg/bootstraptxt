WHAT IT DOES
Use gap utilities to control the space between elements in flexbox or grid
layouts. Includes support for individual row and column gaps.

HOW TO USE IT
Utility classes follow `{property}-{value}` and can be added to any element.
Add a breakpoint prefix to apply one only from that size up: `md:m-3`. Values
in `{braces}` are placeholders.

READING GUIDE
`code` marks a class name, attribute, or value you type into your HTML. Code
blocks are complete and ready to paste into a page that loads Bootstrap 6.
Indentation inside code is meaningful. New to Bootstrap? Read "00 Beginner's
Guide.txt" first.

========================================================================
OVERVIEW
========================================================================

Use gap utilities to control the space between children in flexbox and grid
layouts. Gap utilities are built from a default Sass map ranging from `0` to
`3rem` (`.gap-0` through `.gap-12`). Use utilities like `.gap-3` and `.gap-5`
to control the gap between all children:

Example code (HTML):

<div class="d-flex gap-3">...</div>
<div class="d-flex gap-5">...</div>

NOTE:
  Support note: Gap utilities work with CSS Grid and Flexbox layouts. They are a
  modern alternative to margin utilities for spacing children within a
  container.

========================================================================
NOTATION
========================================================================

Gap utilities that apply to all breakpoints, from `xs` to `2xl`, have no
breakpoint prefix in them. This is because those classes are applied from
`min-width: 0` and up, and thus are not bound by a media query. The remaining
breakpoints, however, do include a breakpoint prefix.

The classes are named using the format `{property}-{size}` for `xs` and
`{breakpoint}:{property}-{size}` for `sm`, `md`, `lg`, `xl`, and `2xl`.

Where property is one of:

- `gap` - for classes that set `gap`
- `row-gap` - for classes that set `row-gap`
- `column-gap` - for classes that set `column-gap`

Where size is one of:

- `0` - for classes that eliminate the `gap` by setting it to `0`
- `1` - (by default) for classes that set the `gap` to `$spacer * .25`
- `2` - (by default) for classes that set the `gap` to `$spacer * .375`
- `3` - (by default) for classes that set the `gap` to `$spacer * .5`
- `4` - (by default) for classes that set the `gap` to `$spacer * .75`
- `5` - (by default) for classes that set the `gap` to `$spacer * 1`
- `6` - (by default) for classes that set the `gap` to `$spacer * 1.25`
- `7` - (by default) for classes that set the `gap` to `$spacer * 1.5`
- `8` - (by default) for classes that set the `gap` to `$spacer * 1.75`
- `9` - (by default) for classes that set the `gap` to `$spacer * 2`
- `10` - (by default) for classes that set the `gap` to `$spacer * 2.25`
- `11` - (by default) for classes that set the `gap` to `$spacer * 2.5`
- `12` - (by default) for classes that set the `gap` to `$spacer * 3`

(You can add more sizes by adding entries to the `$spacers` Sass map
variable.)

========================================================================
EXAMPLES
========================================================================

------------------------------------------------------------------------
FLEXBOX GAP
------------------------------------------------------------------------

Use `gap` utilities to control the space between children in a flexbox
container:

Example code (HTML):

<div class="d-flex gap-4">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
</div>

------------------------------------------------------------------------
GRID GAP
------------------------------------------------------------------------

Gap utilities also work with CSS Grid layouts:

Example code (HTML):

<div class="d-grid gap-3" style="grid-template-columns: 1fr 1fr;">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
  <div>Item 4</div>
</div>

------------------------------------------------------------------------
ROW AND COLUMN GAPS
------------------------------------------------------------------------

Use `row-gap` and `column-gap` utilities to control the space between rows and
columns independently:

Example code (HTML):

<div class="d-grid row-gap-4 column-gap-2" style="grid-template-columns: 1fr 1fr 1fr;">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
  <div>Item 4</div>
  <div>Item 5</div>
  <div>Item 6</div>
</div>

------------------------------------------------------------------------
FLEXBOX WITH WRAPPING
------------------------------------------------------------------------

You can also use `row-gap` and `column-gap` utilities with flexbox layouts
that wrap:

Example code (HTML):

<div class="d-flex flex-wrap row-gap-3 column-gap-2">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
  <div>Item 4</div>
  <div>Item 5</div>
</div>

========================================================================
RESPONSIVE
========================================================================

All gap utilities are responsive and include all breakpoints.

- `.gap-0` through `.gap-12`
- `.sm:gap-0` through `.sm:gap-12`
- `.md:gap-0` through `.md:gap-12`
- `.lg:gap-0` through `.lg:gap-12`
- `.xl:gap-0` through `.xl:gap-12`
- `.2xl:gap-0` through `.2xl:gap-12`

- `.row-gap-0` through `.row-gap-12`
- `.sm:row-gap-0` through `.sm:row-gap-12`
- `.md:row-gap-0` through `.md:row-gap-12`
- `.lg:row-gap-0` through `.lg:row-gap-12`
- `.xl:row-gap-0` through `.xl:row-gap-12`
- `.2xl:row-gap-0` through `.2xl:row-gap-12`

- `.column-gap-0` through `.column-gap-12`
- `.sm:column-gap-0` through `.sm:column-gap-12`
- `.md:column-gap-0` through `.md:column-gap-12`
- `.lg:column-gap-0` through `.lg:column-gap-12`
- `.xl:column-gap-0` through `.xl:column-gap-12`
- `.2xl:column-gap-0` through `.2xl:column-gap-12`

------------------------------------------------------------------------
SASS UTILITIES API
------------------------------------------------------------------------

Gap utilities are declared in our utilities API in `scss/_utilities.scss`.
Learn how to use the utilities API.

Example code (SCSS):

"gap": (
  responsive: true,
  property: gap,
  class: gap,
  values: $spacers
),
"row-gap": (
  responsive: true,
  property: row-gap,
  class: row-gap,
  values: $spacers
),
"column-gap": (
  responsive: true,
  property: column-gap,
  class: column-gap,
  values: $spacers
),
