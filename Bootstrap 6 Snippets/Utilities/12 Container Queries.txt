CONTAINER QUERIES
Bootstrap 6.0  |  Utilities reference
Source: https://getbootstrap.com/docs/6.0/utilities/container-queries
========================================================================

WHAT IT DOES
Turn an element into a query container with container-type utilities so
descendants can respond to its size.

HOW TO USE IT
Utility classes follow `{property}-{value}` and can be added to any element.
Add a breakpoint prefix to apply one only from that size up: `md:m-3`. Values
in `{braces}` are placeholders.

READING GUIDE
`code` marks a class name, attribute, or value you type into your HTML. Code
blocks are complete and ready to paste into a page that loads Bootstrap 6.
Indentation inside code is meaningful. New to Bootstrap? Read "00 Beginner's
Guide.txt" first.

Class             Styles
----------------  ----------------------------
.contains-inline  container-type: inline-size;
.contains-size    container-type: size;

Use the `.contains-*` utilities to set the `container-type` property,
establishing an element as a query container. Once an element is a query
container, its descendants can adapt their styles based on the container’s
size rather than the viewport.

Apply `.contains-inline` to query on inline size (width in horizontal writing
modes), or `.contains-size` to query on both inline and block size.

Example code (HTML):

<div class="contains-inline">
  <div class="card">...</div>
</div>

Example code (SCSS):

// Classes
.contains-inline {
  container-type: inline-size;
}
.contains-size {
  container-type: size;
}

NOTE:
  `.contains-size` queries the container’s block size as well, so the element
  must have an explicit height for `size` containment to resolve. When in doubt,
  reach for `.contains-inline`.

Several components rely on a query container to enable their responsive
layouts. For example, wrap a `.card-group` or a horizontal `.list-group` in an
element with `.contains-inline` so their container-query-based layouts take
effect.

------------------------------------------------------------------------
SASS UTILITIES API
------------------------------------------------------------------------

Container utilities are declared in our utilities API in
`scss/_utilities.scss`. Learn how to use the utilities API.

Example code (SCSS):

"container": (
  property: container-type,
  class: contains,
  values: (
    "inline": inline-size,
    "size": size,
  )
),
