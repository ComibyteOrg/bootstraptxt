WHAT IT DOES
Use justify-content utilities to change the alignment of flex items on the
main axis.

HOW TO USE IT
Utility classes follow `{property}-{value}` and can be added to any element.
Add a breakpoint prefix to apply one only from that size up: `md:m-3`. Values
in `{braces}` are placeholders.

blocks are complete and ready to paste into a page that loads Bootstrap 6.

========================================================================
OVERVIEW
========================================================================

Use `justify-content` utilities on flexbox containers to change the alignment
of flex items on the main axis (the x-axis to start, y-axis if
`flex-direction: column`). Choose from `start` (browser default), `end`,
`center`, `between`, `around`, or `evenly`.

========================================================================
BASIC USAGE
========================================================================

Example code (HTML):

<div class="d-flex justify-content-start">...</div>
<div class="d-flex justify-content-end">...</div>
<div class="d-flex justify-content-center">...</div>
<div class="d-flex justify-content-between">...</div>
<div class="d-flex justify-content-around">...</div>
<div class="d-flex justify-content-evenly">...</div>

------------------------------------------------------------------------
SASS UTILITIES API
------------------------------------------------------------------------

Justify content utilities are declared in our utilities API in
`scss/_utilities.scss`. Learn how to use the utilities API.

Example code (SCSS):

"justify-content": (
  responsive: true,
  property: justify-content,
  values: (
    start: flex-start,
    end: flex-end,
    center: center,
    between: space-between,
    around: space-around,
    evenly: space-evenly,
  )
),
