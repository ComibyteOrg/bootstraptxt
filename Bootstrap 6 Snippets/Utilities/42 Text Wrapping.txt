WHAT IT DOES
Utilities for controlling text wrapping, overflow, and word breaking behavior.

HOW TO USE IT
Utility classes follow `{property}-{value}` and can be added to any element.
Add a breakpoint prefix to apply one only from that size up: `md:m-3`. Values
in `{braces}` are placeholders.

========================================================================
WRAPPING
========================================================================

Control how text wraps inside an element with `text-wrap` utilities. This is a
newer CSS property that replaces the older `white-space` property and adds new
functionality.

Example code (HTML):

<div class="text-wrap">…</div>
<div class="text-nowrap">…</div>
<div class="text-balance">…</div>
<div class="text-pretty">…</div>

========================================================================
WORD BREAK
========================================================================

Prevent long strings of text from breaking your components' layout by using
`.text-break` to set `word-wrap: break-word` and `word-break: break-word`. We
use `word-wrap` instead of the more common `overflow-wrap` for wider browser
support, and add the deprecated `word-break: break-word` to avoid issues with
flex containers.

Example code (HTML):

<p class="text-break">mmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmm</p>

------------------------------------------------------------------------
SASS UTILITIES API
------------------------------------------------------------------------

Text wrapping utilities are declared in our utilities API in
`scss/_utilities.scss`. Learn how to use the utilities API.

Example code (SCSS):

"text-wrap": (
  property: text-wrap,
  class: text,
  values: wrap nowrap balance pretty,
),

Example code (SCSS):

"word-wrap": (
  property: word-wrap word-break,
  class: text,
  values: (break: break-word),
),
