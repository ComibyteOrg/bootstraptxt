WHAT IT DOES
Use place-items utilities to control the alignment of grid items within their
grid areas on both the block and inline axes simultaneously.

HOW TO USE IT
Utility classes follow `{property}-{value}` and can be added to any element.
Add a breakpoint prefix to apply one only from that size up: `md:m-3`. Values
in `{braces}` are placeholders.

========================================================================
OVERVIEW
========================================================================

Use `place-items` utilities on CSS Grid containers as a shorthand to set both
`align-items` and `justify-items` at once. This property controls how grid
items are positioned within their grid areas on both axes.

========================================================================
BASIC USAGE
========================================================================

Use `place-items` utilities to control the alignment of grid items. Choose
from `start`, `end`, `center`, or `stretch` (browser default).

Example code (HTML):

<div class="d-grid place-items-start">...</div>
<div class="d-grid place-items-end">...</div>
<div class="d-grid place-items-center">...</div>
<div class="d-grid place-items-stretch">...</div>

------------------------------------------------------------------------
SASS UTILITIES API
------------------------------------------------------------------------

Place items utilities are declared in our utilities API in
`scss/_utilities.scss`. Learn how to use the utilities API.

Example code (SCSS):

"place-items": (
  responsive: true,
  property: place-items,
  values: (
    start: start,
    end: end,
    center: center,
    stretch: stretch,
  )
),
