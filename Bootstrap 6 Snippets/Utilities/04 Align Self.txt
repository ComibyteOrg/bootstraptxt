WHAT IT DOES
Use align-self utilities to individually change the alignment of flex items on
the cross axis.

HOW TO USE IT
Utility classes follow `{property}-{value}` and can be added to any element.
Add a breakpoint prefix to apply one only from that size up: `md:m-3`. Values
in `{braces}` are placeholders.

READING GUIDE

blocks are complete and ready to paste into a page that loads Bootstrap 6.
Indentation inside code is meaningful. New to Bootstrap? Read "00 Beginner's

========================================================================
OVERVIEW
========================================================================

Use `align-self` utilities on flexbox items to individually change their
alignment on the cross axis (the y-axis to start, x-axis if `flex-direction:
column`). Choose from the same options as `align-items`: `start`, `end`,
`center`, `baseline`, or `stretch` (browser default).

========================================================================
BASIC USAGE
========================================================================

Example code (HTML):

<div class="align-self-start">Aligned flex item</div>
<div class="align-self-end">Aligned flex item</div>
<div class="align-self-center">Aligned flex item</div>
<div class="align-self-baseline">Aligned flex item</div>
<div class="align-self-stretch">Aligned flex item</div>

------------------------------------------------------------------------
SASS UTILITIES API
------------------------------------------------------------------------

Align self utilities are declared in our utilities API in
`scss/_utilities.scss`. Learn how to use the utilities API.

Example code (SCSS):

"align-self": (
  responsive: true,
  property: align-self,
  values: (
    auto: auto,
    start: flex-start,
    end: flex-end,
    center: center,
    baseline: baseline,
    stretch: stretch,
  )
),
