WHAT IT DOES
Control the opacity of elements.

HOW TO USE IT
Utility classes follow `{property}-{value}` and can be added to any element.
Add a breakpoint prefix to apply one only from that size up: `md:m-3`. Values
in `{braces}` are placeholders.

READING GUIDE
`code` marks a class name, attribute, or value you type into your HTML. Code
blocks are complete and ready to paste into a page that loads Bootstrap 6.
Indentation inside code is meaningful. New to Bootstrap? Read "00 Beginner's
Guide.txt" first.

Class         Styles
------------  --------------
.opacity-0    opacity: 0;
.opacity-25   opacity: 0.25;
.opacity-50   opacity: 0.5;
.opacity-75   opacity: 0.75;
.opacity-100  opacity: 1;

The `opacity` property sets the opacity level for an element. The opacity
level describes the transparency level, where `1` is not transparent at all,
`.5` is 50% visible, and `0` is completely transparent.

Set the `opacity` of an element using `.opacity-{value}` utilities.

Example code (HTML):

<div class="opacity-100">...</div>
<div class="opacity-75">...</div>
<div class="opacity-50">...</div>
<div class="opacity-25">...</div>
<div class="opacity-0">...</div>

------------------------------------------------------------------------
SASS UTILITIES API
------------------------------------------------------------------------

Opacity utilities are declared in our utilities API in `scss/_utilities.scss`.
Learn how to use the utilities API.

Example code (SCSS):

"opacity": (
  property: opacity,
  values: (
    0: 0,
    25: .25,
    50: .5,
    75: .75,
    100: 1,
  )
),
