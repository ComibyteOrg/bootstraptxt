WHAT IT DOES
Control how users can select text content with user-select utilities.

HOW TO USE IT
Utility classes follow `{property}-{value}` and can be added to any element.
Add a breakpoint prefix to apply one only from that size up: `md:m-3`. Values
in `{braces}` are placeholders.

READING GUIDE
`code` marks a class name, attribute, or value you type into your HTML. Code
blocks are complete and ready to paste into a page that loads Bootstrap 6.
Indentation inside code is meaningful. New to Bootstrap? Read "00 Beginner's
Guide.txt" first.

========================================================================
OVERVIEW
========================================================================

Change the way in which the content is selected when the user interacts with
it using user-select utilities.

========================================================================
BASIC USAGE
========================================================================

Example code (HTML):

<p class="user-select-all">This paragraph will be entirely selected when clicked by the user.</p>
<p class="user-select-auto">This paragraph has default select behavior.</p>
<p class="user-select-text">This paragraph will only allow the text to be selected when clicked by the user, even if the CSS <code>user-select</code> property is set to something else.</p>
<p class="user-select-none">This paragraph will not be selectable when clicked by the user.</p>

========================================================================
USE CASES
========================================================================

- `.user-select-all` - Useful for code snippets, IDs, or other content users
  might want to copy entirely
- `.user-select-auto` - Default browser behavior, allows normal text selection
- `.user-select-text` - Forces text to remain selectable, useful for
  overriding a `user-select: none` set by an ancestor
- `.user-select-none` - Prevents text selection, useful for UI elements,
  buttons, or decorative text

NOTE:
  Accessibility note: Be careful when using `user-select: none` as it can
  interfere with assistive technologies and keyboard navigation. Ensure that
  important content remains accessible through other means.

SASS UTILITIES API
------------------------------------------------------------------------

User select utilities are declared in our utilities API in
`scss/_utilities.scss`. Learn how to use the utilities API.

Example code (SCSS):

"user-select": (
  property: user-select,
  values: all auto text none
),
